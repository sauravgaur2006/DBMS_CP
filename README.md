# Automatic Index Recommendation System

A database optimization system that analyzes query workloads, recommends candidate indexes, empirically benchmarks performance improvements, and calculates storage overhead.

---

## 👥 Team Architecture & Workflow

| Role | Responsibility | Input File | Output File |
| :--- | :--- | :--- | :--- |
| **Person 1** | Database Schema & Workload | Raw Database | `workload.csv` |
| **Person 2** | SQL Workload Analyzer | `workload.csv` | `data/analyzed_workload.json` |
| **Person 3** | Index Recommendation Engine / ML | `data/analyzed_workload.json` | `data/recommendations.json` |
| **Person 4 (This Module)** | Benchmarking Engine & Streamlit Dashboard | `data/recommendations.json` | `data/benchmark_results.json` |

## 🚀 Quickstart Guide

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Benchmarking Script (`benchmark.py`)
To evaluate the recommended indexes against your MySQL database:
```bash
python benchmark.py
```
*(Configure database credentials in `db_config.json`)*

**Offline Simulation Mode** (no live database required):
```bash
python benchmark.py --simulate
```

### 3. Launch the Streamlit Dashboard (`app.py`)
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8502` to inspect interactive Plotly latency charts, speedup percentages, and storage overhead breakdowns.

## 🔬 Benchmark Methodology (Person 4)
1. **Control Test**: Measures execution latency before index creation using `time.perf_counter()` (1 warmup run + 3 timed iterations).
2. **Apply Index**: Executes `CREATE INDEX` on MySQL table.
3. **Experimental Test**: Measures execution latency after index creation.
4. **Storage Calculation**: Queries `information_schema.TABLES` (`INDEX_LENGTH`) to calculate physical storage overhead in Megabytes.
5. **State Reset**: Executes `DROP INDEX` to ensure clean, isolated testing for each candidate.
